\begin{figure}[t]
  \centering
  \includegraphics[width=\textwidth]{figures/lam_nwm/overview.pdf}
  \caption{\textbf{Design choices for transferable latent actions and navigation world models.}
  \textbf{(a) LAM objectives.} $E_{\mathrm{LAM}}$ extracts latent action $z$ from a frame pair.
  Four variants reconstruct navigation actions, future pixels, future DINO features, or pixels and actions jointly.
  \textbf{(b) NWM architecture and pretraining.} A shared frozen VAE encodes context and target frames.
  Shared patch embedding with positional embeddings produces clean context tokens and noisy target tokens.
  Each CDiT block in $F_\theta$ applies target self-attention, cross-attention with context keys and values, and an FFN.
  Diffusion timestep $\tau$, relative frame offset $\Delta t$, and motion condition $h_m$ form
  $c=E_\tau(\tau)+E_\Delta(\Delta t)+h_m$, which controls adaptive normalization and block gates.
  The output predicts noise and variance for the diffusion objective; inference iteratively denoises and decodes with the frozen VAE.
  NWM-Real trains on Base data with $a\!\rightarrow\!E_a$.
  NavAnywhere pretraining uses no motion branch (TimePT), $g\!\rightarrow\!E_g$ (GeoPT), or $z\!\rightarrow\!E_z$ (LatentPT).
  Dashed VGGT and LAM paths denote offline annotation.
  \textbf{(c) Two-step fine-tuning on Base data.} Reset replaces $E_z$ with $E_a$; Align matches $E_a(a)$ to frozen $E_z(z)$; Action2Latent uses $E_z(E_a(a))$.
  Step 1 trains only $E_a$; Step 2 trains the active NWM path, retaining the frozen teacher for Align and updating $E_z$ for Action2Latent.
  Inference requires real actions without the LAM extractor.}
  \label{fig:lam-nwm-design}
\end{figure}
